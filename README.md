# Check-In Córdoba - Sistema de Gestión Hotelera

## 🏨 Introducción
Check-In Córdoba es una plataforma pensada para digitalizar la administración de pequeños hoteles y hospedajes familiares en la provincia de Córdoba. 

**Problema que resuelve:** Muchos alojamientos regionales aún dependen de planillas de papel o archivos aislados, lo que genera errores en las reservas (overbooking) y dificulta el control de los servicios adicionales que consumen los huéspedes. Este sistema centraliza toda esa información en un solo lugar.

## 🚀 Funcionalidades
* **Landing Page:** Página principal atractiva para promocionar el hotel y los atractivos turísticos de la zona.
* **Gestión de Reservas:** Visualización en tiempo real de la disponibilidad de habitaciones.
* **Control de Usuarios:** Sistema de acceso seguro con roles diferenciados (Administrador y Recepcionista).
* **Registro de Consumos:** Módulo para cargar servicios extra (desayunos, excursiones, productos regionales) a la cuenta del pasajero.

## 🛠️ Instrucciones de ejecución (Maqueta)
Actualmente, el proyecto se encuentra en fase de maquetado estático (HTML5 y CSS3). Para visualizarlo:
1. Clona este repositorio o descarga los archivos.
2. Navega hasta la carpeta `frontend/`.
3. Abre el archivo `index.html` en tu navegador preferido.
